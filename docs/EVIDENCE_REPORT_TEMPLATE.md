# Public evidence report template

**Blank template — no tests, actual results, trading performance or independent assurance are recorded here.**

Use only after actual evidence is reviewed and separately approved for public disclosure. Never attach private logs, fixtures, wallet addresses, credentials, internal paths, signing details or private artefacts. Unknowns must remain unknown.

## Interpretation

Distinguish expected and observed outcomes. Record failures and unresolved questions. Paper trading or simulation does not establish live execution performance; execution costs, liquidity, fees and slippage can differ. An isolated pass does not establish profitability, independent certification or production readiness.

No testing, signing, wallet access or trading is authorised by this template. See the [publication checklist](PUBLICATION_CHECKLIST.md) and [testing methodology](TESTING.md).
